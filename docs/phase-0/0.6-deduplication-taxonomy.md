# Phase 0.6 — Deduplication & Taxonomy POC

Phase 0.6 converts source-backed `EventCandidate` records into conservative canonical events while preserving every source record.

Matching uses title, time, venue, geography and description. Hard date/time or geography contradictions block automatic merging. Only high-confidence matches auto-merge; probable and review matches stay separate for later adjudication.

Clustering is representative-based rather than unrestricted transitive union-find, preventing A≈B and B≈C from automatically merging A with C.

Canonical `evt1:` records retain candidate IDs, source/external IDs, evidence hashes, authority tiers, match evidence and surviving disagreements. Higher-authority sources control displayed conflicting fields without deleting lower-authority evidence.

Taxonomy version `tax1` deterministically assigns the Phase 0.1 categories, food/drink subcategories and independent attributes. Source hints and title evidence are preferred over generic descriptive wording. AI remains a future low-confidence fallback.

Validation: 32/32 Phase 0.6 tests passed plus Python compile validation.

Phase 0.7 will reuse these provenance and clustering principles for local-news ingestion and story clustering.
