# Taxonomy and Search Tags

Primary event categories: food_drink, music, arts_culture, sports, family_kids, outdoors, nightlife, community, government_civic, education, business_networking, shopping_markets, gaming, seasonal_holiday, festival_fair, charity_volunteer, other.

Initial food subcategories: food_trucks, restaurant, brewery, farmers_market, tasting, food_festival.

**Tags are independent from categories.** An event can be `arts_culture` and also carry `museum`, `family_friendly`, `indoor`, `free`, and `accessible`. Tags are controlled searchable/filterable keys grouped into facets such as audience, cost, setting, access, venue type, topic, impact, and change.

News categories: public_safety, government_civic, traffic_transportation, weather_environment, schools_education, business_development, food_drink_business, health, community, arts_entertainment, sports, utilities_infrastructure.

News tags include focused topics such as road_closure, traffic, development, housing, restaurant_opening, business_opening, public_safety, police, fire, crime, schools, elections, utilities, water, health, weather, transit, budget, construction, emergency, service_change, opening, and closure.

Relative views such as `today`, `tonight`, and `this_weekend` are computed at query time rather than stored as durable tags.
