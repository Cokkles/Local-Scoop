# Local News POC

Phase 0.7 ingests local-news evidence through the shared dynamic source catalog, applies POC-market geography relevance, assigns a primary news category plus controlled searchable tags, preserves source provenance, isolates source failures, and conservatively clusters overlapping coverage without deleting individual publisher stories.

See `docs/phase-0/0.7-local-news-ingestion.md` for scope and validation details.
